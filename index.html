What does uploading your save do?

Uploading your save is used with Ability Randomizer and Learnset Randomizer. The general pokemon info will change to match your specific randomizer seed.

Advanced Search Guide

Use boolean expressions with parentheses, and, and or.

(bst >= 600 and type = dragon)

(atk < 100 and type = fairy)

(moveset has ('counter', 'mirror coat'))

Number attributes: hp, atk, def, spa, spatk, spd, spdef, spe, speed, bst, dex, dexid.

String attributes: name. Use = for exact match and has/have for substring match.

List attributes: type, types, ability, abilities, moveset, moves, move, evolution, evolutions, item, items, egggroup, egggroups.

Hardcore-aware list attributes: hardcoreability, hardcoreabilities, hardcoremove, hardcoremoves, hardcoremoveset.

Attribute names are case-insensitive, so BST, bst, ATK, and atk all work.

For list attributes, = and has/have both mean the Pokemon must contain the requested entry. Comparing against a tuple means it must contain every listed value.

name has 'dra'

ability = 'as one'

hardcoreabilities = infiltrator

moveset = tackle

moveset has ('stealth rock', 'spikes')

location has 'route 3'

locationoriginal has 'route 3'

ability ~ ('huge power', 'feline prowess')

bst > 500 and not 'arceus'
